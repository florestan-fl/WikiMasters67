Import rules

Paris time, midnight. Leave empty to import everything the site still shows.
Purchases dated inside the period you had already tracked by hand always get “Non”, so your existing FIFO matching is not disturbed.
Rows without a site ID are linked to a site transaction with the same card and price whose date is within this window. 0 disables matching.
