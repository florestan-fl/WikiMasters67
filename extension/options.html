Cartes suivies

Seules les transactions de ces cartes comptent dans les statistiques (profit, stock, graphiques). Toutes vos transactions sont enregistrées quand même : ajouter une carte plus tard reprend tout son historique.

Nom de la carte (titre Wikipédia)Suivie depuis (facultatif)

Mots-clés de catégorie (facultatif)

Suit aussi toute carte dont la description Wikipédia contient ce mot, par exemple « dinosaure » ou « pays ». Ces descriptions sont souvent larges : vérifiez le résultat ci-dessous.

Valorisation du stock

Valeur d'une carte en stock = médiane de vos dernières ventes de cette carte → sinon l'annonce la moins chère vue sur le marché → sinon vos ventes plus anciennes → sinon son prix d'achat.

Google Sheets (facultatif)

Copie toutes les données et statistiques, avec les graphiques, dans une feuille Google que vous pouvez consulter partout. Voir README.md pour créer le script (5 minutes, une seule fois).

« Importer l'historique » reprend une seule fois les onglets Achats / Ventes de la version 1 (y compris les lignes que le site n'affiche plus). « Inclure = Non » devient une exclusion, et les cartes marquées « Oui » deviennent vos cartes suivies si la liste est vide.

Sauvegarde et export

Vos données sont stockées dans ce profil Firefox. Téléchargez une sauvegarde de temps en temps (et avant de désinstaller l'extension : une extension temporaire perd ses données au redémarrage de Firefox).
